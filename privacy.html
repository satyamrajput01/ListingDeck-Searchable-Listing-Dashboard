Privacy Policy

Last Updated: October 15, 2026 · Version 1.1

1. Overview and Architecture

ListingDeck is a client-side web application designed to provide interactive searching and filtering of opportunities. All computational operations—including keyword matching, category filtering, experience level filtering, sorting, and pagination—execute entirely inside your web browser.

2. Information Collection and Handling

Search Queries and Active Filters: Any search keywords, selected categories, work mode preferences, or sort orders you select are processed in volatile browser memory. They are not transmitted to, collected by, or stored in any remote database or external analytics service.

Personal Information: ListingDeck does not require user accounts, passwords, or personal profiles. We do not ask for or collect names, email addresses, resumes, or application documents.

Cookies and Tracking: The application does not deploy advertising cookies, tracking pixels, or cross-site tracking scripts.

Server Access Logs: As with standard web servers and content delivery networks, hosting platforms automatically log standard, non-personally identifiable technical connection data (including client IP addresses, browser user-agent headers, and request timestamps) solely for network routing, DDoS mitigation, and server security.

3. External Links and Third Parties

Listing cards and dialogs may contain external reference hyperlinks (such as to example.com or technical specifications). When navigating to external destinations:

  • External websites are governed by their respective privacy policies and terms of service.
  • All external links are configured with rel="noopener noreferrer" to prevent window.opener hijacking and protect your browsing session.
  • ListingDeck does not endorse or control external third-party content.

4. Security Controls

We implement proactive frontend security measures, including a strict Content Security Policy (CSP), client-side input sanitization, text-node DOM rendering to prevent Cross-Site Scripting (XSS), and strict protocol verification for hyperlinks.
